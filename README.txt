TouchSwitch v3.5 — Prompt-free startup release

NEW: Windows 11 Task Scheduler opt-in to launch the app elevated at sign-in
without a new UAC popup every restart. Setup offers this option and asks
for admin approval once. The scheduled task starts a protected copy of
TouchSwitch from Program Files, not the writable per-user install folder.

Enable/disable later in Settings > Prompt-free startup. Uninstall removes
the task and protected copy after administrator approval.

All v3.4 features are retained: tray toggling, global keybind, the compact
Windows 11-style UI, Fluent icons, animations and DND-friendly notifications.

Opening the app directly may still prompt for elevation.

Windows 11 ARM64 (Snapdragon X Elite) and x64 (Intel/AMD) supported.
This build has not yet been validated on a physical Windows PC.
